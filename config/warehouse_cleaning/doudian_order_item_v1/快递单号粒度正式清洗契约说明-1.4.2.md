# 抖店订单物流快递单号粒度正式清洗契约说明

## 1. 正式目标

本次将已通过验证的 **DWD_抖店订单物流快递单号粒度影子表**
（`dwd_trade_order_logistics_tracking_no_shadow_1_3_3`）正式化为
**DWD_抖店订单物流快递单号粒度事实全量快照表**
（`dwd_trade_order_logistics_tracking_no_df`）。

正式表一行代表一个店铺订单下的一个快递单号，技术主键为：

```text
店铺ID(shop_id) + 店铺订单号(shop_order_id) + 快递单号(tracking_no)
```

包裹ID不是目标业务粒度，不进入正式表；包裹层数值字段已按快递单号汇总，平均型指标按快递单号取平均。

## 2. 输入与重建边界

影子表审批时使用的是 ODS `2026-07-23` 快照。当前 ODS 已滚动到 `2026-07-24`，因此本次正式化使用已通过质量门禁的影子结果作为一次性重建输入，确保正式候选表与审批结果一致，不把新的 ODS 快照混入本次发布。

这不是物理改名：发布流程会重新创建正式候选表，复制已批准结果，执行质量门禁，原子切换正式表，再清理影子表和临时对象。

## 3. 字段和类型规则

| 中文字段 | 物理字段 | 规则 |
| --- | --- | --- |
| 数据快照日期 | `snapshot_date` | 日期类型 |
| 店铺ID | `shop_id` | 非空标识，字符串 |
| 店铺订单号 | `shop_order_id` | 非空标识，字符串 |
| 快递单号 | `tracking_no` | 非空业务主键，字符串 |
| 物流公司名称列表 | `logistics_company_names` | 按快递单号去重拼接 |
| 最早/最晚发货时间 | `first_shipped_at` / `latest_shipped_at` | 上海时区时间 |
| 包裹记录数 | `package_count` | 包裹ID仅用于汇总计数 |
| 物流商品关系行数 | `package_product_row_count` | 快递单号粒度计数 |
| 商品子单数及列表 | `sku_order_count` / `sku_order_ids` | 快递单号粒度去重汇总 |
| 发货商品数量合计 | `shipped_product_count` | 数值汇总 |
| 物流金额 | `guarantee_amount`、`platform_delivery_*_amount` | 源单位分转元，保留两位小数 |
| 物流商品单价平均值 | `avg_product_price_amount` | 源单位分转元，按快递单号取平均 |

空值转 `NULL`，非空非法值进入异常统计，合法零值保留为零；金额保留源值正负号。

## 4. 发布和回滚

正式发布使用 `candidate_swap`。ClickHouse 只保留当前正式对象，历史版本通过 Git 中的 SQL、契约、发布报告和标签重建；不创建物理备份表。正式发布成功后，影子表和候选/临时对象由同一发布包清理。
