| 项目 | 内容 |

| 契约版本 | `1.2.0` |

## 2. 源数据判断

- 源表是接口窗口全量快照，不代表历史永久全量。
- 当前接口最多查询近 90 天，源表当前快照分区为 `2026-07-21`。
- 当前源表有 52,431 条订单主单。
- `订单详情信息`（`sku_order_list`）是商品明细 JSON 数组，展开后有 90,279 条商品明细。

## 3. 粒度和主键

目标表一行代表：一个店铺订单中的一个商品明细数组元素。

技术主键为：

```text
店铺订单号（shop_order_id） + 商品明细序号（item_index）
```

其中 `item_index` 是源 JSON 数组中的 1 起始序号，不宣称为抖店业务子订单号。当前快照中技术主键数为 90,279，与展开行数一致。不得使用商品 ID（`product_id`）或 SKU ID（`sku_id`）直接去重。

## 4. 统一清洗规则

### 4.1 JSON 处理

- 接口文档字段树共登记 622 个路径：502 个标量字段、68 个对象字段、52 个数组字段。
- 502 个标量字段全部进入字段展开契约；对象字段递归展开到标量叶子字段。
- `shop_order_list` 是接口响应传输容器，当前 ODS 已一行一个店铺订单主单，因此不重复生成传输容器表。
- 订单级字段进入订单主单事实表（`dwd_trade_order_df`），商品级字段进入商品明细事实表（`dwd_trade_order_item_df`）。
- `sku_order_list` 商品明细数组保留店铺订单号（`shop_order_id`）和 1 起始商品明细序号（`item_index`）。
- 除 `shop_order_list` 外的 51 个业务数组按父级主键和 `json_item_index` 拆分为独立子关系。
- 当前 ODS 不可观测的响应页字段 `page`、`size`、`total` 已登记，不伪造值、不静默删除。
- DWD 不保留原始 JSON；接口文档未定义但运行时出现的字段进入隔离和异常统计。

### 4.2 标识、数量和时间

| 中文字段名 | 物理字段名 | 清洗规则 |
| --- | --- | --- |
| 数据快照日期 | `snapshot_date` | 按 `年-月-日` 解析 |
| 店铺ID | `shop_id` | 去除首尾空格，空值阻断主键关联 |
| 店铺订单号 | `shop_order_id` | 去除首尾空格，不能为空 |
| 商品明细序号 | `item_index` | JSON 数组 1 起始序号 |
| 商品ID | `product_id` | 优先使用非空商品标识 |
| SKU ID | `sku_id` | 按标识符处理，不转金额或数量 |
| 商品数量 | `item_quantity` | 解析为整数，解析失败进入异常统计 |
| 直播间ID | `room_id` | 空值和 `0` 统一为 `NULL` |
| 达人ID | `author_id` | 空值和 `0` 统一为 `NULL` |
| 支付时间 | `paid_at` | Unix 秒转上海时区时间，`0` 转 `NULL` |
| 下单时间 | `created_at` | Unix 秒转上海时区时间 |
| 订单更新时间 | `updated_at` | Unix 秒转上海时区时间 |

### 4.3 金额字段

金额单位按字段判断，不能因为同一张表存在一个“分”字段，就把全部金额字段统一除以 100。

| 中文字段名 | 来源字段 | 目标字段 | 单位证据 | 当前动作 |
| --- | --- | --- | --- | --- |
| 商品支付金额 | `sku_order_list.pay_amount` | `item_paid_amount` | 官方接口说明“支付金额（单位：分）” | 分转元，除以 100 |
| 商品原价 | `sku_order_list.goods_price` | `goods_amount` | 用户确认按元 | 按元直接解析，统一保留两位小数 |

已确认的公共规则：

- 目标金额统一保留两位小数，目标类型为 `Decimal128(2)`。
- 负数保留源值符号，不取绝对值。
- 空字符串或空值转换为 `NULL`，不算非法值。
- 非空但无法解析的值进入异常统计，不静默转零。
- `0` 是合法金额，保留为零，不转换为 `NULL`。

### 4.4 枚举字段

只对具有离散业务含义的字段做枚举识别，不对金额、数量、ID、时间和自由文本做枚举扫描。

当前枚举候选字段：

- 广告环境类型（`ad_environment_type`）
- 下单端编码（`order_entry_code`）
- 下单场景编码（`order_scene_code`）
- 支付方式编码（`payment_type_code`）
- 商品订单状态编码（`order_status_code`）
- 主流程状态编码（`main_status_code`）

未知枚举值保留并标记，不静默映射为空。枚举字典当前状态为 `reviewed`，OpenMetadata 中的枚举版本仍记录为 `pending`，待业务审批后再升级正式版本。

## 5. 质量门禁

正式执行前必须通过：

1. 源主单数与展开商品明细数对账。
2. 店铺订单号加明细序号唯一性检查。
3. 商品 ID、SKU ID 非空检查。
4. 数量、时间和已确认金额字段解析检查。
5. 空值数量与非法值数量分别统计。
6. 直播间和达人缺失情况单独统计，不伪造归属。
7. DWD 结果不包含原始 JSON。
8. OpenMetadata 表、字段、标签、自定义属性回读通过。

当前质量结果：商品明细 90,279 行，技术主键 90,279 个；商品 ID、SKU ID、数量和金额解析异常均为 0。直播间 ID 空值或 `0` 为 51,936 行，达人 ID 空值或 `0` 为 45,840 行。
