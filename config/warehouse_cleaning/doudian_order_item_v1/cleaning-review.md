## 已确认规则

| 规则 | 当前结论 | 执行动作 |
| --- | --- | --- |
| 金额单位 | 按字段自身、接口字段说明或已审批字典逐字段判断 | 有明确单位证据才换算；无证据阻断 |
| 商品支付金额（`sku_order_list.pay_amount`） | 接口文档明确“支付金额（单位：分）” | 分转元，除以100 |
| 商品原价（`sku_order_list.goods_price`） | 用户确认单位为元 | 直接按元解析，统一保留两位小数，不除以100 |
| 金额精度 | 统一保留两位小数 | 目标类型 `Decimal128(2)` |
| 负数 | 保留源值符号 | 不取绝对值 |
| 空值 | 空字符串、空值进入 `NULL` | 不记为非法值 |
| 非法值 | 非空且无法解析的值进入异常统计 | 不静默转零 |
| 零值 | 零是合法金额 | 保留为零，不转 `NULL` |
| JSON | 接口文档定义的 622 个路径全部登记；502 个标量字段全部展开；68 个对象递归展开；业务数组拆成 51 个关系 | DWD 不保留原始 JSON；根传输容器 `shop_order_list` 因 ODS 已一行一单而不重复落表 |

## JSON 全字段展开边界

- 订单级标量进入抖店订单主单事实表（`dwd_trade_order_df`）。
- 商品级标量进入抖店订单商品明细事实表（`dwd_trade_order_item_df`），粒度为店铺订单号 + 商品明细数组序号。
- 嵌套 JSON 对象递归展开到标量叶子字段。
- 订单级和商品级数组分别按父级主键 + `json_item_index` 拆分为独立子关系，不能用数组字符串或原始 JSON 代替。
- 接口响应页的 `page`、`size`、`total` 共 3 个字段在当前 ODS 结构中不可观测，已登记为 `not_observable_in_current_ods`，不得伪造值。
- 接口文档未定义但运行时出现的字段进入隔离和异常统计，不能静默丢弃。
