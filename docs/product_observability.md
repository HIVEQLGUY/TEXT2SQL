# Product Observability Notes

取数 Agent 的测试台不只验证最终结果，还要帮助测试人员复盘“跑到哪一步、每一步花了多久、慢在哪里、错在哪里”。

## Runtime Flow

当前取数测试记录以下节点：

- 解析用户请求
- 准备 SQL
- 审查 SQL 安全性
- 执行 SQL 查询
- 生成报表看板
- 记录本次运行

元数据引导模式记录：

- 解析用户请求
- 读取表结构
- 理解业务语义
- 记录本次运行

## Duration Display

页面必须使用业务用户可读的耗时单位：

- 小于 1 秒：`320 毫秒`
- 1 到 60 秒：`3.2 秒`
- 超过 60 秒：`1 分 12 秒`
- 超过 1 小时：`1 小时 08 分`

不要只显示 `s`，不要要求用户自行换算。

## Summary Pattern

每次运行顶部优先展示：

```text
总耗时 3.2 秒 · 最慢节点：执行 SQL 查询，3.2 秒 · SQL 执行 3.2 秒，占 99%
```

每个节点展示：

```text
执行 SQL 查询
成功 · 开始 16:12:58 · 结束 16:13:01 · 耗时 3.2 秒
数据库返回 4 行
```

## Highlight States

- 成功：绿色
- 失败：红色
- 被拦截：红色
- 等待确认：橙色
- 执行中：蓝色
- 普通提示：灰色

SQL 审查中的高风险，例如笛卡尔积，应默认暂停并等待用户确认。
