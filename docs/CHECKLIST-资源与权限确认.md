# 资源与权限确认清单

## 1. 云服务器

待确认：

- 服务器公网 IP：
- 操作系统：
- CPU / 内存 / 磁盘：
- SSH 用户：
- 是否有 sudo/root 权限：
- 是否允许安装 Docker：
- 是否有安全组/防火墙限制：

建议：

- Kibana、Qdrant Dashboard、Embedding docs 等调试入口默认不直接暴露公网。
- 管理入口优先通过内网、VPN 或 SSH 隧道访问。

## 2. 元数据库

待确认：

- 使用 MySQL 还是 PostgreSQL：
- 是否新建数据库：
- host：
- port：
- 管理员账号提供方式：
- 应用账号是否需要我创建：
- 是否需要开启外网访问：

建议账号：

- `meta_admin`：初始化和迁移使用。
- `meta_app`：后端读写元数据使用。
- `meta_readonly`：只读查看和调试使用。

## 3. 抖音主题域数据源

待确认：

- 数据库类型：
- host：
- port：
- database/schema：
- 第一批表名：
- 只读账号：
- 是否需要白名单：
- 是否有分区字段：
- 是否有大表查询限制：

建议：

- 问数执行只使用只读账号。
- 第一批表先控制在一个主题域内，避免上下文过宽。

## 4. 钉钉 AI 表格

待确认：

- 钉钉开放平台应用类型：
- app_key：
- app_secret 提供方式：
- AI 表格/多维表格标识：
- 表元数据 sheet/table 标识：
- 字段元数据 sheet/table 标识：
- 是否已有字段 ID：
- 是否需要我设计钉钉表字段映射：

建议：

- 钉钉 token 不写入仓库。
- 同步任务记录每次读取的版本或更新时间。

## 5. 大模型

待确认：

- 模型服务商：
- base URL：
- API Key 提供方式：
- 默认模型：
- 是否支持 JSON/schema 输出：
- 是否有并发、速率、费用限制：

建议：

- SQL 生成模型和普通总结模型可先共用，后续再拆。
- 所有模型输出都要经过结构化解析和安全校验。

## 6. 检索服务

待确认：

- 是否允许部署 Qdrant：
- 是否允许部署 Elasticsearch/OpenSearch：
- 是否需要 Kibana/OpenSearch Dashboards：
- 是否有 GPU：
- 是否部署独立 Embedding 服务：

建议：

- 第一阶段先确定服务选型，再写索引层代码。
- 检索层保留接口，避免后续更换组件时影响问数流程。

## 7. Git 和部署

待确认：

- 是否创建远程 GitHub/GitLab 仓库：
- 是否需要我提交阶段性 commit：
- 是否需要部署到服务器：
- 是否需要域名和 HTTPS：
