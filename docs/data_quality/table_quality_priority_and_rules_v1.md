# 表级数据质量治理优先级与规则建议 v1

更新时间：2026-07-09

## 1. 生成口径

本清单基于 StarRocks/BI 元数据聚合生成，未扫描业务明细数据，未读取 SQL 明文、配置 JSON 明文或个人敏感字段。评分综合表资产、字段字典、物理活跃度、分区/tablet、任务血缘、SQL 审计聚合、报表/数据集使用关系。命名和分层只作为弱证据，不单独决定表角色。

- 覆盖表数：984
- P0 核心治理表：17
- P1 高优先级表：94
- P2 中优先级表：325
- P3 低优先级/观察表：548

详细清单见 `docs/data_quality/table_quality_priority_inventory.csv`。

## 2. 评分解释

- 价值证据：报表卡片引用、分析项目引用、产出任务、任务下游、SQL 审计命中、资源关系引用、owner。
- 风险证据：大表、宽表、分区多、无主键、空表、物化关系、存储量高。
- 降权证据：长期未使用且无报表、SQL、任务消费证据。

## 3. 推荐规则模板

第一阶段建议全部只预警、不阻断。规则稳定后，再对 P0 中少数核心链路启用阻断。

| 场景 | 推荐规则 | 说明 |
| --- | --- | --- |
| 所有 P0/P1 表 | 表级行数非零；行数 7/30 天波动 | 防静默缺失和异常暴涨暴跌 |
| 有分区字段表 | 最新分区非空；最新分区及时；分区行数波动 | 防新增分区缺失 |
| 有主键表 | 主键重复检查 | 物理主键不等于业务唯一真实成立 |
| 订单/商品/店铺表 | 订单号/商品编码/店铺字段空值率 | 防维度关联失败 |
| 金额/费用/推广表 | 金额非负；异常极值；费用字段空值率 | 防成本价、推广费、退款金额异常 |
| 报表底表/物化表 | 来源 collection 完整性；物化表行数波动 | 防 BI 使用表不完整 |
| API ODS 表 | 原始记录落地行数；采集日期完整性 | 防接口返回成功但数据缺页 |

## 5. 使用建议

1. 先审 P0/P1 表的规则建议，人工确认哪些是真核心生产链路。
2. 对每张 P0 表先配置行数波动、最新日期/分区、主键重复、关键字段空值四类基础规则。
3. 对成本价、推广费、退款、佣金、平台服务费等金额类字段，先只做非负和空值率预警，阈值用历史分位数再校准。
4. 对长期未使用且无报表/SQL 消费的 P3 表，不建议优先配置质量规则，应先做资产归档/下线确认。
5. 后续配置到 BI 质量规则页面时，优先用内置表规则和任务成功行数规则；字段规则不可用时，转成 SQL 规则。
